# Icebreaker Chat landing page

A single-file landing page (`index.html`) with a light/dark toggle.

Stats, reviews, activity pop-ups and the online-members grid stay hidden until real data is added. Edit the `SITE_DATA` block in the script, or set its `endpoint` to an API. Add `#demo` to the URL to preview the layout with clearly labelled sample data.

The sign-up form is not connected to a server yet.
